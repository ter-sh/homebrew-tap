# Homebrew tap

Personal Homebrew formulae maintained by
[ter-sh](https://github.com/ter-sh).

## Install

```bash
brew install ter-sh/tap/<formula>
```

Homebrew adds the tap automatically on first install. Formulae can then be
upgraded or removed with the standard commands:

```bash
brew upgrade <formula>
brew uninstall <formula>
```

Formula updates are proposed through pull requests from their upstream release
workflows and validated on macOS and Linux before merging.
