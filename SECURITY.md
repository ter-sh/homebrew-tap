# Security policy

## Supported versions

Only the latest formula revisions on the default branch are maintained with
security fixes. Older formula revisions may remain available for users who
pin a version, but they are not supported.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
[security advisory form](https://github.com/go-min/homebrew-tap/security/advisories/new)
and include:

- the affected formula and version;
- the operating system and Homebrew version;
- reproduction steps and observed impact; and
- relevant logs with credentials, tokens, and personal paths removed.

Reports involving formula source URLs, checksums, arbitrary command execution,
or workflow and release integrity are especially important. Reports are
reviewed on a best-effort basis; please allow time for investigation and a
coordinated fix before public disclosure.
